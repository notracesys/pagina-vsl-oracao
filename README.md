# São Bento - Oração Sagrada

Este é um projeto Next.js construído no Firebase Studio para a landing page da Oração Sagrada de São Bento.

## Como subir para o seu GitHub

Para enviar este código para o seu repositório no GitHub, siga estes passos no terminal do seu editor:

1. **Crie um repositório vazio** no seu GitHub (não adicione README, licença ou .gitignore lá, pois já temos aqui).
2. **Abra o terminal** aqui no editor.
3. **Inicialize o Git**:
   ```bash
   git init
   ```
4. **Adicione os arquivos**:
   ```bash
   git add .
   ```
5. **Faça o primeiro commit**:
   ```bash
   git commit -m "Primeiro commit da landing page São Bento"
   ```
6. **Conecte ao seu repositório remoto**:
   Substitua `<URL_DO_SEU_REPOSITORIO>` pelo link que o GitHub te deu (ex: `https://github.com/seu-usuario/seu-repositorio.git`).
   ```bash
   git remote add origin <URL_DO_SEU_REPOSITORIO>
   ```
7. **Defina a branch principal e envie**:
   ```bash
   git branch -M main
   git push -u origin main
   ```

## Tecnologias Utilizadas

- **Tailwind CSS**
