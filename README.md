# São Bento - Oração Sagrada

Este projeto é uma landing page de alta conversão no estilo "VSL Jornalística" para a Oração de São Bento.

## Como subir para o seu GitHub

Siga estes passos no terminal. Se você recebeu o erro **"remote origin already exists"**, use o Passo 4 atualizado abaixo:

1. **Inicialize o repositório**:
   ```bash
   git init
   ```
2. **Adicione os arquivos**:
   ```bash
   git add .
   ```
3. **Commit inicial**:
   ```bash
   git commit -m "Landing Page São Bento - Estilo VSL Jornalística"
   ```
4. **Conecte ao seu repositório remoto (Correção para o erro de Origin)**:
   Crie um repositório no GitHub e substitua o link abaixo. Use este comando para forçar a atualização do link:
   ```bash
   git remote set-url origin https://github.com/SEU_USUARIO/SEU_REPOSITORIO.git || git remote add origin https://github.com/SEU_USUARIO/SEU_REPOSITORIO.git
   ```
5. **Envie os códigos**:
   ```bash
   git branch -M main
   git push -u origin main
   ```
